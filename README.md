# Data Science Projects Portfolio

A collection of data science and machine learning notebooks covering retail sales prediction, financial market analysis, and geopolitical impact studies.

## Notebooks

### [Big Mart Sales Prediction](Big_Mart_Sales_Prediction.ipynb)
Predicts item sales across retail outlets using XGBoost. Covers data preprocessing, missing value imputation, and categorical feature encoding to build a sales forecasting model on the BigMart dataset (1559 products across 10 stores).

### [Sales Prediction](sales_prediction.ipynb)
Builds a sales forecasting model using retail outlet data with various item and outlet characteristics. Includes feature engineering, missing value handling, and exploratory data analysis to predict item outlet sales.

### [Data Analysis – NIFTY 50](Data_analysis.ipynb)
Market analysis of the NIFTY 50 index with calculations for daily price changes, volatility, and USD-INR exchange rates. Covers data from 2015–2025.

### [E-commerce Sales Analysis](Ecommers_sales_analysis.ipynb)
Analyzes superstore e-commerce data with interactive Plotly visualisations examining monthly sales trends, customer segments, and product categories.

### [Economic & Political Event Impact Study](Economic_and_Political_Event_Impact_Study.ipynb)
Studies the impact of economic and political events on NIFTY 50 performance using Logistic Regression, Random Forest, and XGBoost models. Predicts market movements within a 3-day window following identified events.

### [Geopolitics Analysis](Geopolicts_analysis.ipynb)
Identifies NIFTY 50 market regimes and macro stress using Hidden Markov Models, incorporating price data, USD-INR exchange rates, and macro events for comprehensive regime analysis.

### [Market Impact](market_impact.ipynb)
Automatically detects and visualises significant market events in NIFTY 50 data through volatility and return thresholds. Clusters related market movements and analyses their impact on stock prices and the USD-INR exchange rate.

## Technologies Used

- **Python** – pandas, NumPy, scikit-learn, XGBoost
- **Visualisation** – Plotly, Matplotlib, Seaborn
- **Machine Learning** – Classification, Regression, Hidden Markov Models
- **Finance** – NIFTY 50 index data, USD-INR exchange rates
